## 四、推荐

### 首选推荐：安徽师范大学（AHNU）

**推荐理由**：
1. 录取规则复杂度最高（A/B段 + 技能大赛免试/面试 + 综合分计算 + 多级计划调整 + 外校调剂），是对Schema的极限压力测试
2. 有联合培养（2所），与HFNU的联培模式形成对比
3. 体育教育综合分引入了新的量纲（公共课×80%+专业课×120%），验证分数模型的扩展性
4. 招生章程为HTML，可直接解析
5. 省属重点大学，官方数据长期稳定性最高

**预计的Schema挑战**：
- 综合分计算（`score_basis` 可能需要新值 `weighted_composite`）
- 技能大赛面试录取（可能需要新的 `candidate_category` 或 `admission_round`）
- 录取分数为查询系统而非静态表格（`source_locator` 需要适配）

**预计不需要修改核心Schema**：现有的 Program Year / Offering / Plan / Score 模型能够表达AHNU的所有业务事实。综合分可通过扩展 `score_basis` 枚举值表达。

### 次选推荐：安徽新华学院（AXHU）

**推荐理由**：
1. 民办vs公办是最大的结构性差异
2. 无联合培养，验证Schema在无联培场景下的正确性
3. PDF格式的招生章程
4. 药学文理兼招（同专业两个方向）

**注意**：建议将AHNU和AXHU分别作为Pilot B和Pilot C，以覆盖公办复杂场景和民办简单场景。
