## 📝 使用说明

### 数据访问

**Python示例**:
```python
import json

# 读取2025年报录比
with open('provincial/statistics/2025年各院校报录比.json', 'r', encoding='utf-8') as f:
    data = json.load(f)
    for school in data:
        print(f"{school['院校']}: {school['报录比']}")

# 读取专业课大纲
with open('institutions/majors/2026/安徽建筑大学_专业课大纲.json', 'r', encoding='utf-8') as f:
    syllabus = json.load(f)
    for major in syllabus['专业']:
        print(f"{major['专业名称']}: {major['专业课1']['科目']}")
```

**CSV访问**:
```bash
# 查看2025年报录比
cat provincial/statistics/2025年各院校报录比.csv | column -t -s,
```

### 数据更新流程

1. **新增院校数据**: 在 `institutions/{院校名}/{年份}/` 下添加文件
2. **新增专业大纲**: 在 `institutions/majors/{年份}/` 下添加JSON
3. **更新统计数据**: 在 `provincial/statistics/` 下更新对应文件
4. **更新报告**: 重新生成本综合报告
